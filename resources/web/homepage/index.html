calibration tests
Temperature
Finds the best nozzle temperature for this filament. Run when corners blob or detail is stringy.
Max volumetric speed
Finds the fastest the hotend can melt without starving. Run before raising speed limits.
Pressure advance
Tunes how far the nozzle moves ahead of its own pressure. Run after changing extruder, filament or temps.
Flow ratio
Measures how much material really lands on the build plate. Run for thin or inconsistent extrusion.
Retraction
Finds the shortest retraction that still stops ooze during travel. Run to cut stringing.
Cornering
Measures speed lost at sharp direction changes. Run when corners look rounded or wavy.
Input shaping frequency
Finds the machine's resonant frequency so input shaping can cancel ringing. Run once per printer.
Input shaping damping
Tunes how hard that ringing gets cancelled. Run after the frequency is set.
VFA
Measures vertical fine artifacts left by high-speed moves. Run when fast prints look rough on the surface.
